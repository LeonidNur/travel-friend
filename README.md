# travel-friend

## Travel Friend — Telegram Mini App для поиска попутчиков и совместного планирования путешествий с помощью ИИ

Проект помогает людям находить подходящую компанию для поездки, знакомиться в чате, обсуждать идеи путешествия и превращать разрозненные желания участников в понятный маршрут, бюджет и план действий.

На этапе MVP продукт реализуется не как отдельное мобильное приложение, а как Telegram Mini App. Это позволяет быстрее проверить гипотезу, упростить вход для пользователей и сократить время разработки.

## Простое объяснение

Если коротко, Travel Friend нужен для того, чтобы человеку было проще:

1. понять, с кем ему комфортно поехать;
2. начать общение без лишних барьеров;
3. договориться о поездке;
4. получить помощь ИИ прямо в процессе обсуждения;
5. собрать из хаотичных пожеланий понятный план поездки.

Для нетехнических участников команды это можно описать так: пользователь открывает Telegram Mini App, заполняет профиль и travel-анкеты, смотрит подходящих людей, пишет им в чат и вместе с ИИ обсуждает будущую поездку.

## Почему Telegram Mini App

На текущем этапе Telegram Mini App выбран как основная форма MVP, потому что:

1. пользователю не нужно ставить отдельное приложение;
2. проще быстро показать работающий продукт;
3. вход для первых пользователей короче и понятнее;
4. проще тестировать гипотезу в реальном Telegram-сценарии;
5. часть пользовательского пути уже встроена в сам Telegram.

Telegram Mini App не отменяет будущую отдельную мобильную версию. Если MVP подтвердит спрос, текущую продуктовую логику можно будет переиспользовать дальше.

## Что уже есть сейчас

Текущий проект находится на стадии базового каркаса.

Уже сделано:

- каркас Next.js Mini App в `apps/mini-app`
- нижняя мобильная навигация
- маршруты для `/`, `/chats`, `/trips` и `/profile`
- определение окружения Telegram SDK
- резервный режим браузера для локальной разработки вне Telegram

Важно: AI-помощник не выделен в отдельную вкладку. Он должен быть встроен в сценарии чатов и поездок, когда эти потоки будут реализованы.

## Текущий статус проекта

Сейчас проект можно описать так:

- заложен фундамент Telegram Mini App;
- есть базовая навигация и маршрутизация;
- есть техническая готовность к дальнейшему развитию профиля, чатов и поездок;
- продуктовая логика ещё будет наращиваться постепенно;
- это пока не законченный пользовательский сервис, а рабочая основа для MVP.

## Идея проекта

У молодых путешественников часто есть желание поехать куда-то, но нет подходящей компании, большого бюджета или опыта самостоятельного планирования. Из-за этого поездка откладывается, становится дороже или вовсе не происходит.

Travel Friend решает эту проблему через сочетание двух механик:

1. Поиск совместимых попутчиков. Пользователь заполняет профиль, указывает интересы, бюджет, стиль отдыха и предпочтения, после чего может искать людей для совместной поездки.
2. AI Travel Copilot. ИИ помогает участникам договориться: анализирует желания группы, предлагает направления, маршруты, примерный бюджет, жильё, транспорт и активности.

## Для кого продукт

Основная целевая аудитория на старте:

- зумеры и молодые путешественники;
- студенты и молодые специалисты;
- люди, которым не хватает компании для поездок;
- пользователи с ограниченным бюджетом;
- люди, которым хочется путешествовать интереснее, дешевле и безопаснее.

При этом продукт может быть полезен и более широкой аудитории: как сервис поиска компании и как AI-помощник для самостоятельного планирования путешествий.

## Главная ценность

Travel Friend не является просто планировщиком путешествий и не является просто приложением знакомств.

Главная ценность проекта — помочь пользователю:

- найти людей с похожими интересами и бюджетом;
- начать обсуждение будущей поездки;
- согласовать желания участников;
- получить понятный план путешествия;
- снизить стоимость поездки за счёт совместного участия;
- сделать путешествие более интересным за счёт компании и геймификации.

## MVP

Цель MVP — проверить ключевую гипотезу:

Люди готовы заполнять профиль, искать компанию для поездки, вступать в чат с потенциальными попутчиками и использовать ИИ, чтобы договориться о совместном путешествии.

В MVP входит:

- запуск Telegram Mini App;
- вход пользователя через Telegram;
- заполнение профиля;
- анкета путешественника;
- поиск потенциальных попутчиков;
- механика взаимного интереса / мэтча;
- создание чата после совпадения;
- обсуждение поездки;
- AI-помощник для согласования поездки;
- генерация черновика маршрута на основе предпочтений участников.

В MVP не входит:

- отдельное мобильное приложение для iOS и Android;
- публикация в App Store и Google Play;
- покупка билетов;
- бронирование отелей;
- полноценная юридическая верификация документов;
- сложная рекомендательная ML-система;
- полноценная геймификация;
- платные подписки;
- маркетплейс украшений профиля;
- интеграции с авиакомпаниями, отелями и туроператорами.

Эти функции могут быть добавлены позже, если MVP подтвердит спрос.

## Базовый пользовательский сценарий

1. Пользователь регистрируется.
2. Заполняет профиль: имя, возраст, город, фото, интересы, языки, стиль общения.
3. Заполняет анкету путешественника: бюджет, даты, направления, тип отдыха, уровень комфорта, желаемый формат поездки.
4. Просматривает профили потенциальных попутчиков.
5. Отмечает интересных людей.
6. При взаимном интересе создаётся чат.
7. Участники обсуждают возможную поездку.
8. ИИ анализирует сообщения и предпочтения участников.
9. ИИ предлагает направление, маршрут, бюджет, активности и компромиссы.
10. Участники получают черновик совместной поездки.

## Основные модули продукта

### Профиль пользователя

Профиль нужен не только для знакомства, но и для доверия.

Профиль может включать:

- имя;
- возраст;
- город;
- фото;
- краткое описание;
- интересы;
- любимые форматы отдыха;
- языки;
- ссылки на соцсети;
- бейджи;
- рейтинг;
- отметки верификации.

### Анкета путешественника

Анкета путешественника помогает понять, с кем пользователю будет комфортно путешествовать.

Возможные поля:

- желаемые направления;
- бюджет;
- даты;
- длительность поездки;
- стиль отдыха;
- уровень комфорта;
- отношение к хостелам, отелям и апартаментам;
- отношение к активному отдыху;
- предпочтения по компании;
- важные ограничения.

### Поиск попутчиков

На первом этапе поиск может работать через простые фильтры и скоринг совместимости.

Примеры критериев:

- совпадение бюджета;
- совпадение дат;
- похожие интересы;
- похожий стиль отдыха;
- комфортный возрастной диапазон;
- совпадение направлений;
- похожие ожидания от поездки.

### Чат

Чат — центральное место, где пользователи знакомятся и обсуждают будущую поездку.

На старте достаточно:

- личного чата после взаимного интереса;
- группового чата для нескольких участников;
- отправки текстовых сообщений;
- сохранения истории;
- возможности вызвать ИИ-помощника.

### AI Travel Copilot

ИИ внутри чата помогает группе перейти от хаотичного обсуждения к конкретному плану.

Функции первой версии:

- суммировать желания участников;
- выделять ограничения;
- предлагать направления;
- предлагать маршрут по дням;
- оценивать примерный бюджет;
- находить компромиссы;
- предлагать активности;
- делать план дешевле, спокойнее или насыщеннее.

## Возможные команды ИИ

Примеры команд:

```text
/summary   — суммировать желания участников
/plan      — предложить план поездки
/budget    — оценить примерный бюджет
/cheaper   — сделать поездку дешевле
/activities — предложить активности
/compare   — сравнить несколько направлений
/conflicts — найти противоречия в желаниях участников
/final     — собрать финальный черновик поездки
```

## Предварительный стек

Предлагаемый стек для MVP:

- Клиент: Telegram Mini App
- Фронтенд: Next.js + React + TypeScript
- Интеграция с Telegram: Telegram Web Apps SDK
- Бэкенд: API routes или server actions
- База данных: Supabase Postgres
- Авторизация: серверная проверка Telegram `initData`
- Хранилище: Supabase Storage или совместимое S3-хранилище
- AI-сервис: отдельный backend-слой для LLM и генерации поездок
- LLM: внешний API на старте
- Дизайн: Figma
- Репозиторий: GitHub

Telegram Mini App не отменяет будущую разработку отдельного мобильного приложения. Если MVP подтвердит спрос, текущую продуктовую логику, базу данных и AI-сценарии можно будет переиспользовать для iOS и Android.
