# MVP Scope

## Главная гипотеза MVP

Люди готовы:

- заполнять профиль путешественника;
- искать компанию для поездки;
- выбирать людей, с которыми хотят создать чат;
- обсуждать поездку в группе;
- использовать ИИ как помощника для договорённостей.

## Что входит в MVP

### 1. Профиль пользователя

Минимальные данные:

- имя;
- возраст;
- город;
- интересы;
- желаемые направления;
- бюджет;
- даты или примерный период поездки;
- стиль путешествия.

### 2. Поиск людей / формат тендера

Пользователь не просто автоматически попадает в группу, а сам выбирает людей, с которыми хочет начать общение.

Базовая логика:

- пользователь видит карточки других путешественников;
- оценивает совпадение по направлению, бюджету и интересам;
- отправляет запрос или выражает интерес;
- при взаимном интересе появляется возможность создать чат.

### 3. Групповой чат поездки

В чате пользователи обсуждают:

- направление;
- даты;
- бюджет;
- жильё;
- транспорт;
- ожидания от поездки.

### 4. AI-copilot в чате

ИИ помогает группе:

- структурировать обсуждение;
- предлагать маршрут;
- сравнивать варианты;
- считать примерный бюджет;
- фиксировать договорённости;
- задавать уточняющие вопросы.

## Что НЕ входит в MVP

На первом этапе не делаем:

- покупку билетов внутри приложения;
- бронирование жилья;
- сложную систему рейтингов;
- полноценную социальную сеть;
- рекомендательную систему на ML;
- автоматическое создание идеальных групп;
- встроенные платежи;
- страховки;
- юридические гарантии безопасности.

## Цель MVP

Проверить, хотят ли люди использовать продукт для поиска компании и обсуждения совместного путешествия.
