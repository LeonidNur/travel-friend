# Safety and Trust

## Почему это важно

Travel Friend — социальный продукт, где незнакомые люди ищут компанию для поездки.  
Поэтому доверие и безопасность должны учитываться с самого начала.

## Базовые меры для MVP

### Профиль пользователя

Минимально нужно:

- имя;
- возраст;
- город;
- описание;
- интересы;
- стиль путешествия.

Позже можно добавить верификацию.

## Жалобы и блокировки

Пользователь должен иметь возможность:

- пожаловаться на другого пользователя;
- заблокировать пользователя;
- выйти из чата;
- скрыть свой профиль.

## Модерация

На MVP можно начать с простой ручной модерации жалоб.

В будущем можно добавить:

- автоматическую проверку сообщений;
- антиспам;
- проверку подозрительного поведения;
- систему доверия.

## Ограничения ответственности

Приложение помогает найти компанию и обсудить поездку, но не гарантирует:

- безопасность участников;
- достоверность всех данных;
- качество поездки;
- выполнение договорённостей.

## Принцип

Безопасность должна быть частью продукта, а не дополнительной функцией “когда-нибудь потом”.
