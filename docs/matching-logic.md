# Matching Logic

## Цель

Matching Logic помогает пользователю найти потенциально совместимых попутчиков.

На MVP не нужна сложная ML-рекомендательная система. Достаточно простого скоринга по ключевым параметрам.

## Основные параметры совместимости

- направление;
- даты;
- бюджет;
- стиль отдыха;
- интересы;
- возрастной диапазон;
- уровень комфорта;
- формат поездки.

## Пример простой логики

Каждый параметр даёт часть общего score:

- совпадение направления — высокий вес;
- совпадение бюджета — высокий вес;
- совпадение дат — высокий вес;
- похожие интересы — средний вес;
- похожий стиль отдыха — средний вес;
- возрастной диапазон — низкий или средний вес.

## MVP-принцип

На первом этапе matching должен быть простым, понятным и объяснимым.

Лучше показать пользователю:  
“Вы похожи по бюджету, датам и стилю отдыха”,  
чем строить сложную непрозрачную систему рекомендаций.
