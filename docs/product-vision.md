# Product Vision

## Идея проекта

Travel Friend — приложение для поиска компании в путешествиях.  
Пользователь может найти людей с похожими планами, бюджетом, интересами и стилем путешествия, создать общий чат поездки и вместе договориться о деталях.

## Проблема

Молодым людям часто хочется путешествовать, но одному это:

- дороже;
- скучнее;
- сложнее организационно;
- менее безопасно;
- психологически менее комфортно.

При этом найти подходящую компанию среди друзей получается не всегда: у людей разные даты, бюджеты, направления и ожидания.

## Решение

Travel Friend помогает пользователю:

- заполнить профиль путешественника;
- найти подходящих людей для поездки;
- создать чат вокруг будущего путешествия;
- обсудить маршрут, бюджет, жильё, транспорт и ожидания;
- использовать ИИ-помощника для упрощения договорённостей.

## Главная ценность

Проект помогает не просто “спланировать маршрут”, а найти людей, с которыми этот маршрут хочется пройти.

## Ключевой фокус

Главный фокус проекта — не туризм как бронирование, а социальный подбор компании для поездки.

ИИ — важный помощник, но не замена человеческому выбору.
