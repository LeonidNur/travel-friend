# Monetization

## Базовая идея

На MVP монетизация не является главным фокусом.  
Сначала нужно проверить, готовы ли люди пользоваться продуктом для поиска компании и обсуждения путешествий.

## Возможные модели монетизации

### 1. Freemium

Бесплатный базовый функционал:

- профиль;
- поиск людей;
- базовые чаты.

Платные функции:

- расширенные фильтры;
- больше запросов;
- умный AI-помощник;
- приоритетное отображение.

### 2. Подписка

Пользователь платит за расширенные возможности:

- AI-планирование поездок;
- детальные маршруты;
- бюджетные сценарии;
- подбор группы.

### 3. Партнёрские комиссии

В будущем можно зарабатывать на:

- бронировании жилья;
- билетах;
- страховках;
- экскурсиях;
- travel-сервисах.

### 4. B2B / комьюнити

Потенциально продукт можно использовать для:

- студенческих поездок;
- клубов путешественников;
- организаторов туров;
- локальных сообществ.

## На MVP

Главная метрика — не выручка, а подтверждение спроса.

Важно понять:

- хотят ли люди искать попутчиков;
- доверяют ли они механике подбора;
- помогает ли ИИ договориться;
- готовы ли пользователи возвращаться в продукт.
