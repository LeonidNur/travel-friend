# Feature List

## MVP-функции

### Telegram Mini App

- открытие приложения внутри Telegram;
- получение данных пользователя через Telegram;
- базовый экран входа / приветствия.

### Профиль

- имя;
- возраст;
- город;
- фото;
- описание;
- интересы;
- языки;
- стиль отдыха.

### Travel-анкета

- направления;
- бюджет;
- даты;
- длительность поездки;
- тип отдыха;
- уровень комфорта;
- ограничения.

### Поиск попутчиков

- карточки пользователей;
- фильтры;
- простая оценка совместимости;
- интерес / лайк;
- взаимный мэтч.

### Чат

- чат после мэтча;
- групповой чат;
- текстовые сообщения;
- вызов AI Travel Copilot.

### AI Travel Copilot

- summary;
- plan;
- budget;
- cheaper;
- activities;
- compare;
- conflicts;
- final.

## После MVP

- полноценная геймификация;
- рейтинги;
- верификация;
- подписки;
- интеграции с travel-сервисами;
- отдельное мобильное приложение.
