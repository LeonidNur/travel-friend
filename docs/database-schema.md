# Database Schema

Этот документ больше не фиксирует источник истины для модели данных.

С 2026-08-06 проект завершил этап логической доменной модели и утвердил ER-модель. Physical schema, таблицы БД, миграции, RLS и persistence-проектирование ещё не выполнялись и не должны выводиться напрямую из старых frontend- или draft-документов.

До начала schema-этапа источником истины являются:

- [docs/backend/domain-model.md](./backend/domain-model.md)
- [docs/backend/er-diagram.md](./backend/er-diagram.md)
- [docs/backend/backend-architecture.md](./backend/backend-architecture.md)

Когда команда перейдёт к schema-этапу, этот документ должен быть переписан уже как производный артефакт от утверждённой логической модели, а не как самостоятельная предварительная схема.
